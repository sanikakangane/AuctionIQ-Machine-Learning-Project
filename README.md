## 📌 About The Project

**AuctionIQ** is a machine learning-based application designed to predict the auction prices of Indian Premier League (IPL) players using their historical cricket performance statistics.

The project explores how machine learning and data analytics can be applied to sports analytics to estimate player valuations.

By analyzing batting, bowling, and overall performance indicators, AuctionIQ generates estimated player auction prices using regression algorithms.

The system implements two machine learning models:

- **Linear Regression**
- **Random Forest Regressor**

These models are used to generate predictions and compare their performance using standard regression evaluation metrics.

The primary objective is to demonstrate how historical cricket data can be transformed into meaningful insights through predictive modelling.

## 🤖 Machine Learning Models

AuctionIQ uses two regression algorithms to estimate IPL player auction prices.

### 1. Linear Regression

Linear Regression is a supervised machine learning algorithm that establishes a mathematical relationship between input features and a target variable.

In AuctionIQ, it analyzes player performance statistics to estimate auction prices and serves as a baseline prediction model.

### 2. Random Forest Regressor

Random Forest Regressor is an ensemble learning algorithm that combines multiple decision trees to generate predictions.

It helps capture complex relationships between different player performance statistics and auction prices.

### Model Comparison

Both models are evaluated using the same dataset and evaluation methodology to understand their predictive performance.

## 📈 Model Evaluation Metrics

AuctionIQ uses the following regression evaluation metrics to measure and compare model performance.

| Metric | Description |
|---|---|
| MAE (Mean Absolute Error) | Measures the average absolute difference between actual and predicted values. |
| MSE (Mean Squared Error) | Measures the average squared prediction error. |
| RMSE (Root Mean Squared Error) | Measures prediction error in the original target unit. |
| R² Score | Measures how well the model explains variations in auction prices. |

These metrics help determine how effectively each algorithm predicts player auction prices.

## 🔄 Project Workflow

The development of AuctionIQ follows these major stages:

1. **Data Collection:** Collect historical IPL player performance and auction price information.
2. **Data Preprocessing:** Clean the dataset and handle missing or inconsistent values.
3. **Exploratory Data Analysis:** Analyze player statistics and identify patterns.
4. **Feature Engineering:** Prepare relevant batting, bowling, and overall performance features.
5. **Model Development:** Implement Linear Regression and Random Forest Regressor.
6. **Model Training:** Train the algorithms using historical player data.
7. **Model Validation:** Evaluate model performance using validation data.
8. **Model Testing:** Assess the final models using separate holdout data.
9. **Price Prediction:** Generate estimated auction prices based on player statistics.
10. **Model Evaluation:** Compare model performance using regression metrics.

## 🗂️ Dataset Strategy

AuctionIQ follows a season-based approach to explore the relationship between historical player performance and subsequent auction prices.

| Dataset Role | Season Mapping |
|---|---|
| Training | 2022 → 2023 |
| Training | 2023 → 2024 |
| Validation | 2024 → 2025 |
| Final Holdout Testing | 2025 → 2026 |

The final holdout dataset is kept separate from the training and validation process to provide an independent evaluation.

**Data Coverage Note:** The available IPL 2024 dataset contains 71 matches instead of the expected 74 matches. This is a known data coverage limitation.

## 🚀 Getting Started

Follow these steps to access the project locally.

### Prerequisites

- Python 3.x
- Node.js and npm
- Git
- Google Colab or a local Python environment

### 1. Clone the Repository

```bash
git clone https://github.com/sanikakangane/AuctionIQ-Machine-Learning-Project.git
```

### 2. Navigate to the Project Directory

```bash
cd AuctionIQ-Machine-Learning-Project
```

### 3. Install Python Dependencies

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

### 4. Install Application Dependencies

```bash
npm install
```

### 5. Run the Application

Start the application using the development command configured in the project's `package.json`.

**Note:** The machine learning development environment and web application may require separate setup depending on the project structure.
